# Completeness v2 — grading worksheet
Grade each pair `complete`, `minor` or `major` against [`RUBRIC.md`](RUBRIC.md) (which is v1's, verbatim).
**The only question:** what did the source say that the rewrite no longer says?
Condensing is not loss. Frontmatter is not the note. A dropped identifier is `major`. A source that cuts off mid-sentence has lost nothing if the rewrite says so.
Order is random, so you can stop at any point — the analysis stays valid on however many you finish. Replace `?` on each Grade line.
