> **Historical record.** Entries before 2026-06-24 reference "ADR NNNN". These point to decisions we folded into the living designs under [Designs](Designs). We preserve the older ADR names exactly as written. They represent what actually shipped at the time.

This page provides the combined build timeline for agentm and its sibling toolkit [crickets](https://github.com/alexherrero/crickets). The table contains one row per shipped feature in the order it landed. This gives you a single answer for what we built and when we built it. Read the table top-to-bottom to follow the story. Read the mapping section below to see which release tag carries a given roadmap era. Several major roadmap milestones shipped inside ordinary "Minor" point releases instead of receiving a major version bump. These include the whole V6 memory engine, most of V7, and the bulk of V8/Autonomy. The authoritative version history remains in [`CHANGELOG.md`](https://github.com/alexherrero/agentm/blob/main/CHANGELOG.md) for agentm and its [crickets counterpart](https://github.com/alexherrero/crickets/blob/main/CHANGELOG.md). We maintain this page so you can understand what shipped and why without reading every commit.

**Coverage note.** Every row from 2026-06-18 forward covers both repos at feature granularity. This window starts with agentm v5.6.0 and crickets v3.20.0. A dedicated release-archaeology pass (E4, 2026-07-10) drafted these rows feature-by-feature from the git and PR history of both repos. Rows before that date come from agentm's own release history one release at a time. We do not independently itemize crickets releases before v3.20.0 here. No feature-level source covers that earlier window yet. We can backfill the crickets pre-window history later if it receives its own archaeology pass. This will not disturb anything below it.
